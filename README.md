## 🇨🇳 中文

把同一套巨物美学锁到任意题材上的本地风格锁。核心锁的十条不变量——尺度标尺、庇护逻辑、机位克制、透光与次表面散射、色彩边界、负空间、材质等比放大、构图、情绪边界——全部来自 20 张参考图与 4 段参考视频逐帧逐像素实测（1866 真实帧）的明度、饱和度、高饱和像素占比、纯黑与过曝上限、冷暖共存、镜头长度与剪辑节奏、画幅比例。它把通常被混为一谈的三层彻底分开：题材无关的核心锁（不许改）、4 个已验证子风格（明亮粉彩、清冷雨中、仙侠宏大、云海仙宫）、完全开放的题材层，因此同一套风格可套用到植物、建筑、机械、生物、道具、织物或地貌。输出是可直接粘贴的图像与视频提示词，并附零依赖像素校验器，报告出图在八项可测阈值上的通过与不通过。

### ✨ 能做什么

- 十条题材无关的核心锁逐条落到提示词里，一条都不省
- 核心锁内不含任何题材词，同一风格可套植物、建筑、机械、生物、道具、织物、地貌
- 4 个已验证子风格：明亮粉彩、清冷雨中、仙侠宏大、云海仙宫；不够用可按扩展框架新建（须继承核心锁）
- 图像提示词走十槽装配骨架、视频提示词走运镜词表与剪辑节奏，均为成品直出，拿到就能粘贴
- 零依赖像素校验器（Node，支持 PNG／JPEG），报告八项可测阈值的通过与不通过
- 附参考素材实测档案，明确写出素材没有提供什么，避免把素材题材误写进风格定义

## 🇬🇧 English

A local style lock that applies one colossal-scale aesthetic to any subject. Its ten subject-agnostic invariants — scale anchor, shelter logic, camera discipline, translucency and subsurface scattering, color boundaries, negative space, material scale-up, framing, and mood boundaries — were derived by measuring 20 reference images and 4 reference videos frame by frame and pixel by pixel (1,866 real frames): luminance, saturation, high-saturation pixel share, black and blown-highlight ceilings, warm/cool coexistence, shot lengths and cutting rhythm, and aspect ratios. It separates the three layers usually conflated: the subject-agnostic core lock (not editable), four verified sub-styles (bright pastel, cold rain, epic xianxia, cloud-palace), and the fully open subject layer — so the same style fits plants, architecture, machinery, creatures, props, fabric, or terrain. It outputs paste-ready image and video prompts plus a zero-dependency pixel checker that reports which of eight measurable thresholds a generated image passes or fails.

### ✨ What it does

- Ten subject-agnostic core invariants, every one of them carried into the prompt with none skipped
- No subject words inside the core lock, so it fits plants, architecture, machinery, creatures, props, fabric, or terrain
- Four verified sub-styles — bright pastel, cold rain, epic xianxia, cloud-palace — plus an extension framework for new ones that must inherit the core lock
- Image prompts run a ten-slot assembly skeleton and video prompts run a camera-word table with cutting rhythm, both paste-ready
- Zero-dependency pixel checker (Node, PNG and JPEG) reporting pass/fail against eight measurable thresholds
- Ships a measured reference archive that states plainly what the source material does not provide
