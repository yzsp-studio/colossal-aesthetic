# 巨物美学 · 风格锁

## 核心任务

把用户的**任意题材**，装配成能产出「巨物美学」的统一风格提示词——**图像与视频提示词都一次成稿，不需要二次加工**；出图后提供**像素级校验**，确认风格真的锁住了。

**本技能锁的是风格，不是题材。** 巨型蘑菇、巨型机械、巨型鲸、巨型书库、巨型织物……都走同一套核心锁。

## 三层结构（先理解这个）

| 层 | 内容 | 是否可变 |
|---|---|---|
| **核心锁** | 十条题材无关的不变量 | **不可变** |
| **子风格** | 光质、明度档位、色温、配色配方、情绪 | 选一个，或按框架新建 |
| **题材** | 具体画什么 | **完全自由** |

**最常见的失败模式**：把参考素材的题材写进风格定义。那样的提示词只能画一个题材，换个题目就散架。**参考素材的题材只允许出现在「示例配方」里。**

## 工作流

**模式 A · 生成提示词（主要用法）**
1. 读 `references/01-风格锁核心.md`（每次都要读）
2. 按核心锁第 4 节第 1 步的三问判断题材可行性；不适合就直说并给替代建议
3. 读 `references/02` 选子风格；都不合适按扩展框架新建（必须继承核心锁）
4. 图像走 `03`，视频走 `04`；**十条核心锁逐条落到提示词里，一条不省**
5. 按 `references/05` 做平台适配
6. 按「输出模板」输出**成品提示词**

**模式 B · 校验已有出图**
```
node scripts/style-check.mjs <图片...> [--ref <参考图目录>] [--json]
```
先量再改，不要凭感觉调。

**模式 C · 反推已有画面的风格**
用量出的色彩指标 + 目视的尺度/机位/透光/庇护性，映射到 `02` 的子风格。不要凭印象描述。

## 硬性规则

1. **锁风格不锁题材**：核心锁里不许出现任何具体题材词。
2. **不许编造数值**：阈值只有两个来源——本技能的实测数据，或参考素材的实测数据。没依据就写「未核实」。
3. **十条核心锁一条不省**：省略哪条，哪条就会漂。
4. **输出成品**：不给半成品、不要求二次加工。
5. **负向约束按平台形态给**：有独立负向框才单独给；没有的改写成正向句式并入同一条。
6. **不生成图片或视频**：只产出方向、配色、提示词与校验。

## 输出模板

```
## 一、题材可行性判断
题材：… ｜ 巨物候选：… ｜ 是否适合：是/否（依据核心锁三问）

## 二、子风格选择
选：… ｜ 理由：… ｜ 光质/明度档位/配色配方：…

## 三、尺度设计
参照物：… ｜ 体量比：… ｜ 庇护性结构：… ｜ 溢出画框方式：…

## 四、提示词（成品）
<完整提示词>
Negative: <仅当该平台有独立负向框>
中文说明：逐槽一行

## 五、怎么用这条提示词
- 一条提示词 = 一张图/一段视频，逐条出，不要合并粘贴
- 正负分开贴；无负向框的平台改写为正向并入正文
- 画幅靠界面或参数设置
- 出图后跑 style-check.mjs 校验
- 迭代时一次只改一个变量

## 六、自查
核心锁十条 ☐×10 ｜ 通用性试金石：删掉题材词后是否仍成立？

## 七、如果效果不对
按 references/06 定位改法；先量再改。
```
