# 巨物美学风格锁 · 使用与维护

一个自包含的本地 Skill：把**同一套「巨物美学」**锁到**任意题材**上，直接产出可粘贴的 AI 制图与 AI 视频提示词，并附像素级校验器。

## 这个技能解决什么问题

风格类技能最常见的失败是**把题材当成了风格**——参考素材里是巨型花卉与人物，于是提示词里写满"荷花、荷叶、汉服"，结果只能画那一个题材，换个题目就散架。

本技能的做法是把三层彻底分开：

| 层 | 内容 | 是否可变 |
|---|---|---|
| 核心锁 | 十条题材无关的不变量 | **不可变** |
| 子风格 | 光质、明度档位、色温、配色配方、情绪 | 选一个，或按框架新建 |
| 题材 | 具体画什么 | **完全自由** |

**通用性试金石**：把提示词里的题材词全部删掉，剩下的话如果仍然描述得出这套美学，才算锁住了风格；否则锁住的是题材。

## 安装

技能根目录只需包含本文件夹（或指向它的符号链接）：

```bash
ln -s /path/to/colossal-aesthetic ~/.dsh/skills/colossal-aesthetic
```

DSH 的 `SKILL.md` frontmatter 使用**严格 YAML 解析**。本技能的 `description` 与 `whenToUse` 使用折叠块标量（`>-`）书写——**改动时不要在未加引号的值里出现英文冒号加空格**，否则整个技能会静默消失、报「unknown or no longer available」。

## 校验器的用法与边界

```bash
node scripts/style-check.mjs <图片...> [--ref <参考图目录>] [--json]
```

- **测什么**：明度中位、饱和度中位、高饱和像素占比、纯黑占比、高光溢出占比、有色像素占比、暖色占比、冷色占比，并逐条对照阈值给出通过/不通过；给了 `--ref` 时额外报告与参考图的偏差。
- **阈值来源**：全部来自参考素材的逐像素实测分布（见 `data/风格实测数据.json`），不是主观设定。20 张参考图在当前阈值下**全部 8/8 通过**。
- **支持格式**：PNG（全质量解码）、基线 JPEG（仅解 DC 系数，得到 1/8 缩略图，色彩统计足够）。**不支持渐进式 JPEG**，遇到了请先转 PNG。
- **JPEG 路径的实测偏差**：与同一帧的 PNG 全质量路径相比，明度中位差 0.9、饱和度中位差 1.2、有色像素占比差 1.1，可忽略；但**高饱和占比会被低估**（实测 0.1% vs 全质量 2.0%），因为 8×8 块平均抹掉了细小的饱和细节。**需要精确判定"高饱和"这一项时，请先把 JPEG 转成 PNG。**
- **零依赖**：不装任何 npm 包，纯 Node 内置模块（自写 PNG 解码器 + JPEG DC 解码器）。解码正确性已与 `ffmpeg` 交叉验证：PNG 路径均值**逐位一致**，JPEG 路径均值差约 2%（源于无色度上采样插值）。
- **测不出来的东西**：尺度标尺是否可辨、巨物是否溢出画框、是否有透光边缘、庇护性是否成立、焦点是否唯一——这些**必须目视**，见 `references/06` 第三节。

## 数据来源与可信度

风格锁不是凭空设计的，是从用户提供的参考素材里**逐帧逐像素测出来的**：

- **20 张 PNG**（约 1800×1000）：全分辨率解码后统计色彩分布。
- **4 个 MP4**（1280×592，约 20fps，共约 93 秒 / **1866 真实帧**）：逐帧 `signalstats` 统计亮度、饱和度、对比度、色相与帧间差分，并做镜头切换检测。

实测得到的几条关键结论（都写进了核心锁）：
- 明度跨度 **18.6–75.7**，暖色占比跨度 **0.5%–59.3%** → **风格不锁定明暗档位与色相主导关系**，只锁边界与关系；
- 高饱和像素中位仅 **3.0%** → 这是"高级灰"的量化标志；
- 纯黑与过曝都被压在 **2.5% / 2.1%** 以下；
- 剪辑以**快剪**为主（镜头长度中位约 2.8 秒），另有一条**一镜到底 31.9 秒**；
- 画幅全部为超宽（2.166:1 至 2.415:1）。

**素材没有提供的东西**（已在 `references/07` 第四节逐条说明）：没有生成参数与提示词、没有 EXIF、音轨内容未分析、未做主观筛选。因此本技能做的是**风格反推**，不是提示词复刻。

## 维护

- **新增子风格**：按 `references/02` 末尾的五步扩展框架新建，必须继承核心锁十条，并回到 `references/01` 第 5 节逐条自查。
- **调整阈值**：阈值必须由实测得出。改之前先跑 `node scripts/style-check.mjs <参考图...> --json` 重新取分布，不要让参考图本身判不过。
- **新增平台**：在 `references/05` 增补，并标注官方来源；查不到就写「未核实」，不要给看起来专业的臆测数字。
- **通用性**：本技能不得出现任何具体项目名、剧名、角色名、地点名或内网路径。参考素材的题材词只允许出现在 `references/02` 的「参考素材示例配方」一节。

## 参考素材的处置

原始参考素材（图片与视频）**未复制进本技能包**，`references/07` 只记录其客观测量结果与文件清单特征，不包含原始文件。这样技能包体积小、可独立分发，同时保留了结论的可追溯性。素材版权仍归原作者所有，本技能只提取风格特征用于提示词生成。
