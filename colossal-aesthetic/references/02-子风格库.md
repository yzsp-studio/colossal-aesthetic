# 子风格库

## 怎么用这份文件

`01-风格锁核心.md` 的十条**永远不变**。本文件的每个子风格只决定四件事：
**光质 → 明度档位 → 色温与配色配方 → 情绪基调**。

子风格的**题材适用面是开放的**：下面每个子风格都标注了"已验证的题材"和"可迁移到的题材类型"，后者是**建议而非限制**——只要满足核心锁第 1 步的三个问题，任何题材都能用任何子风格。

> **关于题材词**：本文件出现的"荷花/荷叶/汉服"等词，是**参考素材的题材标签，不是风格标签**。生成提示词时，这些词只在"使用者恰好要做这个题材"时使用；换成别的题材时，风格描述部分**一个题材词都不该留下**。

## 子风格 A · 明亮粉彩（仙逸清透）

**来源证据**：20 张参考图的大部分 + 视频 `acf1ba0a`（明亮粉彩最典型，实测平均亮度 Y≈116）

| 项 | 配方 |
|---|---|
| **光质** | 大面积高漫射天光 + 柔和侧逆光；光线穿透薄壁形成发光边缘；无硬阴影 |
| **明度档位** | **宽档：L 18–75**。实测 20 张参考图跨度极大（最暗 18.6、最亮 75.7），说明这一子风格**允许同风格下的不同曝光**。偏暗版本必须同步加强雾与空气透视以保住通透感，否则会滑向"压抑" |
| **色温** | 中性偏冷（约 6000–6500K），受光边缘微暖 |
| **配色** | **冷暖对比配方**：青绿/苍碧与淡粉构成冷暖两端，**两端面积比可在 3:7 至 7:3 之间浮动**（实测参考素材里青绿主导与粉色主导两种都有）。另配 20%–30% 高明度素色（象牙白/米白/淡蓝白）作气口。暖端饱和度允许略高于冷端（实测暖色中位 S33.3 vs 冷色 S26.5），但**全图高饱和像素（S>70）不超过 20%** |
| **雾与介质** | 极细腻低空水汽或空气透视，远景逐级淡化 |
| **情绪** | 空灵、仙逸、温柔庇护、可游可居 |
| **已验证题材** | 巨型花卉（荷、莲）+ 人物 + 水面 |
| **可迁移题材** | 巨型发光蕈类、巨型半透明海生生物、巨型纱质织物与垂幔、巨型冰晶、巨型花冠树、巨型伞盖结构的植物 |
| **提示词片段（可直接嵌入）** | `soft high-key daylight, luminous translucent edges, subsurface scattering, muted celadon against dusty rose, delicate mist, serene sheltered atmosphere, gentle ambient occlusion at contact points, saturation kept low with purity only in small accents` |
| **不适用** | 需要庄严压迫感或厚重历史感的题材（此时选 C 或 D） |

## 子风格 B · 清冷雨中（湿润清幽）

**来源证据**：视频 `40e677df`（雨中巨荷、礁石白莲，实测平均亮度 Y≈101、饱和 SAT≈10.5）

| 项 | 配方 |
|---|---|
| **光质** | **全漫射**，无方向性主光；无硬阴影；水面与湿表面有柔和反射；可见细密雨丝或雨雾 |
| **明度档位** | 中调（中位 L≈40–55） |
| **色温** | 偏冷（约 6500–7500K），整体青灰 |
| **配色** | 主 65% 苍青/深青灰；辅 25% 湿白/雾灰；点缀 ≤5% 暗红或冷白花心 |
| **雾与介质** | 雨雾 + 水面湿气，空气透视强，远景几乎溶进灰调 |
| **情绪** | 孤寂、出尘、湿润清幽、克制 |
| **已验证题材** | 雨中巨型花卉 + 撑伞人物 + 礁石海岸 |
| **可迁移题材** | 雨中巨构城市、雾中巨林、湿润巨型岩体、雨中巨型灯阵、潮间带巨型结构 |
| **提示词片段** | `fully overcast diffuse light, no directional sun, rain haze, wet reflective surfaces, muted blue-grey palette, no hard shadows, quiet melancholic shelter` |
| **不适用** | 需要明亮通透仙气的题材（选 A） |

## 子风格 C · 仙侠宏大（史诗崇高）

**来源证据**：视频 `9ce53057`（巨荷峡谷、山岳巨莲、一镜到底 31.9 秒，实测平均亮度 Y≈96、饱和 SAT≈10.8）

| 项 | 配方 |
|---|---|
| **光质** | 低角度侧逆光为主，带**体积光/丁达尔光束**；光线穿过峡谷或林隙形成光柱；中远景有强烈空气透视 |
| **明度档位** | 中调偏高（中位 L≈45–62），明暗对比比 A/B 强，**但暗部仍通透** |
| **色温** | 中性（约 5500–6000K），光束微暖、阴影微冷 |
| **配色** | 主 60% 深青绿/墨碧；辅 30% 雾白与远山灰蓝；点缀 ≤5% 朱红或金 |
| **雾与介质** | 云海、峡谷雾气、体积光束；**纵深层次 ≥ 4 层**（近景遮挡 → 中景主体 → 远景巨物 → 天际） |
| **情绪** | 崇高、壮阔、仪式感、震撼但安全 |
| **已验证题材** | 巨荷峡谷、山岳巨莲、泛舟人物、临海远眺 |
| **可迁移题材** | 巨型峡谷结构、巨型塔林、巨构城市天际线、巨型机械结构群、巨型地质柱状节理、巨型根系或藤蔓峡谷 |
| **提示词片段** | `low-angle rim light, volumetric god rays, layered atmospheric depth, monumental scale, deep teal and misty grey, epic yet serene, vast negative space in mist` |
| **不适用** | 亲密温柔的题材（选 A） |

## 子风格 D · 云海仙宫（庄严史诗）· 建筑巨物

**来源证据**：视频 `128f0ec3`（悬浮殿宇、雕龙巨柱、云海台阶；实测平均亮度 Y≈84.5、饱和 SAT≈7.1，**全套素材中最暗、最低饱和**）

| 项 | 配方 |
|---|---|
| **光质** | 单侧低角度日光 + 大面积云海反射光；建筑受光面与阴影面**明度差大但过渡柔和**；暗部靠云海反射补光，**不是死黑** |
| **明度档位** | 暗调（中位 L≈30–45），是四条子风格里最暗的一档 |
| **色温** | 微冷（约 6000K），受光的暖白石与冷调阴影形成冷暖分区 |
| **配色** | 主 60% 暖灰石色/暗青；辅 30% 云海白与天光蓝；点缀 ≤5% 朱红（如柱、幡、灯）作为唯一暖色锚点 |
| **雾与介质** | 云海、山谷雾、空气透视；建筑层层退远并逐级淡化 |
| **情绪** | 庄严、深邃、崇高、神话史诗、秩序感 |
| **已验证题材** | 悬浮殿宇、巨柱回廊、云海台阶、玉露台 + 少量人物 |
| **可迁移题材** | 巨型人造结构（坝、塔、桥、门、穹顶、船体、机械巨构）、巨型洞窟或矿井、巨型书架/库房、巨型钟表内部、巨型剧场 |
| **提示词片段** | `solemn monumental architecture, colossal columns and arcades, cloud sea beyond, warm stone against cool shadow, restrained palette, ceremonial symmetry, soft reflected fill light, no black crush` |
| **不适用** | 轻快、可爱的题材 |

## 参考素材示例配方（**包括但不限于**中的"包括"）

这是用户参考资料里跑通的**一套具体题材组合**。它**不是风格定义**，而是一个已验证案例，在以下情况下直接照用：

- 使用者明确要复刻参考素材那种画面时；
- 需要给"核心锁 + 子风格"一个具体落地示范时。

| 项 | 取值 |
|---|---|
| 题材组合 | 巨型睡莲科花卉（花瓣、荷叶、莲蓬、茎秆） + 人物 + 平静水面/水乡建筑 |
| 尺度关系 | 单片花瓣相当于数倍人身高；单叶直径相当于数十倍人身宽；人物身高不足叶缘的 1/10 |
| 人物与巨物的互动 | **共生**：以花瓣为舟、沿茎秆行走如过桥、在叶冠下煮茶避雨、倚花瓣小憩 |
| 场景类型 | 东方微缩仙境、水乡宏观生态庭院、晨雾初开的水域 |
| 为什么有效 | 该题材自带"高洁、轻柔"的既有意象，天然消解巨物恐惧，把"压迫"重塑为"庇护"；粉与青绿的古典对比在降饱和后显得清雅 |
| 对应子风格 | A（明亮粉彩）为主；也可套 B 做雨中版、套 C 做仙侠版 |
| 复用要点 | **复用的是"共生互动方式"与"尺度叙事结构"，不是"荷花"这个物件本身** |

## 扩展框架：怎么新建一个子风格

当现有四条都不合适时（例如题材需要暖调、或需要强烈的逆光剪影），按下面五步新建，**并写进本文件**：

1. **定光质**：主光方向与软硬、有无体积光、阴影硬度。**必须满足核心锁 5（必须有透光/次表面散射）和锁 5 的软阴影要求。**
2. **定明度档位**：给出目标 L 中位区间，落在 **30–75** 之间；并明确"暗部不许死黑、亮部不许过曝"。
3. **定配色面积比**：主 50%–65% / 辅 25%–35% / 点缀 ≤5%；主色域给出色相区间；**点缀只能有一个色系**。
4. **定情绪基调**：从"静穆、空灵、庄严、温柔、清幽、崇高"里选，**不得引入恐怖/暴力/末日**。
5. **给出提示词片段**：一段可直接嵌入的英文短语，且**不含任何题材词**。

新建后必须回到 `01-风格锁核心.md` 第 5 节逐条自查，确认十条都没被破坏。
