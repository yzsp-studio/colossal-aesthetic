# 风格校验与迭代

## 一、先量，再改

```bash
node scripts/style-check.mjs <你的出图.png> --ref <参考图目录>
```

输出三个部分：
1. **实测指标**（明度/饱和/高饱和/纯黑/过曝/冷暖/有色像素 + 主色板）
2. **风格锁比对**：8 项逐条通过/不通过，附实测值与目标区间
3. **与参考图的偏差**（给了 `--ref` 时）：明度差、饱和差、色相差

**判读口径**：
- 8/8 → 风格锁锁住；
- 6–7/8 → 局部漂移，按下面第四节改；
- ≤5/8 → 偏离明显，建议重写提示词而不是微调。

支持 PNG（全质量）与 JPEG（1/8 缩略，色彩统计已足够）。**不支持渐进式 JPEG**，遇到就转成 PNG 或基线 JPEG。

## 二、逐项失败 → 对应改法

| 未通过项 | 症状 | 提示词该怎么改 |
|---|---|---|
| **明度L中位偏低** | 画面压暗、发闷 | 加 `high-key soft light`、`bright diffused daylight`、`airy luminous atmosphere`；**不要**靠加曝光解决，要靠加**漫射光与雾** |
| **明度L中位偏高** | 发白、发飘 | 加 `preserve deep mid-tones`、`rich shadow detail`、`controlled contrast`；把负空间从"纯白雾"换成"青灰雾" |
| **饱和度S中位偏高** | 艳、俗 | 加 `muted`, `desaturated`, `dusty`, `weathered`；负向加 `hyper-saturated, vivid colors, neon` |
| **饱和度S中位偏低** | 灰死、没气 | 检查是不是整图无彩；加 `subtle color temperature variation`、`warm accent in the light` |
| **高饱和占比偏高** | 纯色成片 | 把点缀色的面积词去掉；加 `purity only in small accents`；负向加 `pure saturated hues` |
| **纯黑占比偏高** | 暗部糊成黑洞 | 加 `transparent shadows`, `no black crush`, `shadows filled with ambient bounce light`；负向加 `crushed blacks, pitch black shadows` |
| **高光溢出偏高** | 亮部一片死白 | 加 `gentle highlight rolloff`, `no blown highlights`；负向加 `overexposed, blown out white` |
| **有色像素占比偏低** | 接近单色 | 补回冷暖两端；加 `distinct warm and cool zones` |
| **暖侧缺失** | 全冷、寡淡 | 加一处小面积暖：`a single warm accent`（受光边缘、灯、花心、织物） |
| **冷侧缺失** | 全暖、腻 | 把环境介质改成冷调（青灰雾、水色、阴影）或把受光面中性化 |

## 三、目视项（脚本测不出来的）

脚本只能测**色彩层面**。下面几条必须目视，且**同样会导致风格漂移**：

| 目视项 | 不合格的表现 | 改法 |
|---|---|---|
| **尺度标尺** | 缩小到 200px 宽后找不到参照物 | 让参照物更靠近画面中心或加大到 3%–5% |
| **溢出画框** | 巨物完整装进画面 | 加 `extends beyond the frame`, `only part of it fits in frame` |
| **庇护性** | 巨物看起来有威胁感 | 改轮廓词：`arching`, `sheltering`, `curving gently`；删掉一切尖锐/下压/口器形状 |
| **透光边缘** | 巨物边缘是硬的、实的 | 加 `translucent edges`, `subsurface scattering`, `luminous rim` |
| **接触关系** | 人物像贴上去的 | 加 `casting a soft contact shadow`, `ambient light tinting the figure` |
| **唯一焦点** | 不知看哪 | 明确一个焦点，其余虚化或简化 |

## 四、迭代纪律（关键）

**一次只改一个变量。** 同时改风格词、构图和配色，你无法判断是哪一项起了作用，只会陷入反复重掷。

推荐节奏：

1. 一条提示词出 4 张 → 选最接近的 1 张
2. 跑 `style-check.mjs` → 找出**唯一**最严重的未通过项
3. 只针对那一项改提示词 → 再出 4 张
4. 8/8 通过后，再用这张当参考图出同系列其余画面

**不要**做的事：
- 不要靠加长提示词解决漂移（加得越多，注意力越分散）；
- 不要靠改 seed 解决风格问题（seed 只固定噪声初值，**不保证风格一致**）；
- 不要指望六位十六进制色值被模型精确还原（它们在多数模型里只是普通文本）。

## 五、长视频怎么续接（超过平台单次上限时）

参考素材里的 17–32 秒成片很可能是多段生成后拼接的。续接方法：

1. **首段**：按 `04-视频提示词语法.md` 生成到平台上限（如 10 秒）
2. **取尾帧**：从成片里导出最后一帧
3. **续接段**：用该尾帧作为**首帧**，提示词里**重复写入完整视觉系统**（不要写"接着上一段"——模型看不到上一段）
4. **拼接**：在剪辑软件里直接接，或加 6–12 帧的短叠化
5. **校验**：对首段尾帧与续段首帧各跑一次 `style-check.mjs`，**两者指标差不超过 10%** 才算接得住

跨段的连续性检查项：明度差、饱和差、主色板重叠度、光向一致性、巨物形态的连贯性。

## 六、把校验变成习惯

每次交付前问三个问题：

1. **数字上**：`style-check.mjs` 是不是 8/8？
2. **目视上**：第三节那六条有没有一条不合格？
3. **通用性上**：把提示词里的题材词全删掉，剩下的话**是否仍然描述得出这套美学**？

第 3 条是最终试金石——能，说明你锁住的是**风格**；不能，说明你锁住的是**题材**，换个题目就会崩。
